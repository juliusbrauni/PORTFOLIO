# juliusbraun – Portfolio

Statische Website (HTML/CSS), gehostet auf Netlify.

- `index.html` – Startseite (Bilder und Pakete werden im Script oben in `ARBEITEN` und `ANGEBOT` gepflegt)
- `impressum.html`, `datenschutz.html` – Rechtliches
- `css/site.css` – Gestaltung
- `fonts/` – lokal gehostete Schriften (Cormorant Garamond, Newsreader)
- `images/` – Bilder, Weblänge 2000 px

Änderungen: speichern → in VS Code committen und pushen → Netlify veröffentlicht automatisch.
